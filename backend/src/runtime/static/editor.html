    Editor controls

    Mouse

    Click empty canvas
    add a vertex to the active polygon
    Click polygon body
    select that object
    Drag polygon body
    translate the whole object
    Drag vertex
    move that vertex
    Click midpoint dot
    insert a vertex into that edge (auto-drags so you can place it)
    Shift+click vertex
    delete that vertex
    Alt+click polygon
    insert a vertex at click point (nearest edge)

    Keys

    ⌘/Ctrl-Z
    undo last action
    delete / backspace
    delete the selected vertex (or active object if no vertex selected)
    space
    toggle live cursor preview on the projector
    esc
    deselect
    ?
    show / hide this help

    Workflow

    1. New object
    click + New object, then click points on the editor canvas
    2. Bind a device
    pick from the dropdown so clicks on the polygon trigger something at runtime
    3. Fine-tune
    click a vertex to select + drag; use midpoint dots to add detail; shift+click to remove
    4. Save
    writes data/objects.json
